Generated from the radius section of [unique-jewels.md](unique-jewels.md), which is derived from Path of Building's `src/Data/Uniques/jewel.lua` (78 item rows, 76 distinct names; Combat Focus has three variants). Excludes the six timeless jewels and the cluster jewels. Radius values are the client's `PassiveJewelRadii`: Small 800, Medium 1200, Large 1500, Very Large 2000, Massive 2400; Thread of Hope uses the 3_16 Variable rings 960-1320, 1320-1680, 1680-2040, 2040-2400 and 2400-2880. The 42 rows with server-side effects are implemented (`/radius_jewel`); the 33 threshold rows have item sources, the client applies their local mods and the server counts the radius attributes and adds the mapped target stats, while skill-specific consumers remain partial. Lioneye's Fall has an item source and client conversion; its server flag model is missing. Inspired Learning and Warrior's Tale remain inactive. The mechanism and server columns say what each needs.
