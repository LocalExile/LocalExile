A selectable class is complete only after every node, choice, granted effect and drawback has a runtime consumer,
with actual Gateway allocation/refund/failure/reload tests and supported native gameplay evidence.
Raw table membership, panel values and helpers without gameplay callers do not establish a working mechanic.
Use the actual 3.29.3b graph for connected legal builds and free-choice point costs.
Keep unsupported engine behavior explicit and preserve ordinary/unascended play.

[Gambler](gambler.md) records the full node checklist, supported incoming ailment path, verified opt-in prerequisites
and remaining engine limits for this branch.
Other classes require their own acceptance; this change makes no claim about their completion.
