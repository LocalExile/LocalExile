## 2. What is distributed

- Developer execution, C/S and six-witness guides plus the finite coverage/limitation matrix.
- Detailed field/formula/binding references extracted from the frozen source, selectively corrected for current
  delivery wording and links; historical addresses refer only to the pinned executable.
- Scalar reference algorithms and fixed vectors, including a minimal selection from ignored RNG evidence.
- Bounded Frida observer and offline analyzer with synthetic/mock regressions; no recording is bundled.
- Source receipt and explicit fixture/source hashes, without binary images, extracted assets or private traffic.
  The observer retains short site-validation signatures, not function bodies or disassembly dumps.

Detailed references retain local `logs/...` names as audit identifiers.
They are not public downloadable files or required inputs for the offline delivery checks.
The frozen branch retains the original entry, six-witness checklist, long chronological ledger and all ignored
evidence in the original workspace; no historical evidence was rewritten to manufacture closure.

## 3. Evidence classes and verification

The [root evidence definitions](../012-projectile-execution.md#2-evidence-and-interpretation) apply throughout.
The public verification entry is [verify_delivery.py](../../../../scripts/re/projectiles/verify_delivery.py).
Its scalar algorithms execute translated reference code and do not load the pinned PE.
Its probe/analyzer tests use mocks and synthetic events; they are not official captures or an actual Frida attach.

Historical original-instruction controls used explicit providers, terrain, entities, storage/API boundaries and
selected update inputs.
Their reports remain useful corroboration but the full native-byte/harness dependency graph is deliberately not
part of this public package.
The sanitized receipt exposes chosen case outcomes and boundaries for review, not an independently executable
whole-client proof.
The matrix names which claims rely on S/E evidence rather than public T tests.

## 5. Publication and interpretation limits

No game binary, data extraction, disassembly dump, private capture, credential or large interpreter graph is included.
Names/addresses and derived calculations are research descriptions, not recovered official source symbols.
No new live observation, official capture, server behavior, client attach or deployment is claimed.
No global absence of projectile C2S reports, universal prediction policy, complete engine schedule or numerical
damage reconstruction follows from these bounded paths.
